# Brand assets

HACS requires at least an `icon.png` here.

- `icon.png` — 256x256, transparent background
- `logo.png` — optional, wider wordmark

These are for HACS only. Getting the icon to show up *inside* Home Assistant
(on the integrations page) is a separate step: submit it to
https://github.com/home-assistant/brands as a custom integration. That
repository is where Home Assistant's frontend actually loads icons from.
